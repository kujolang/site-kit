# Skip Link

## Purpose

An accessible link for skipping directly to page content.

## When To Use

Use Skip Link when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Skip Link to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See skip-link.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

## Examples

See examples.json and skip-link.html.
