# Video

## Purpose

A responsive video embed frame with caption.

## When To Use

Use Video when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Video to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See video.schema.json for the source contract.

## Variants

- embed
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
