# Slider

## Purpose

A range input for selecting a numeric value.

## When To Use

Use Slider when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Slider to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See slider.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and slider.html.
