# Tooltip

## Purpose

A short contextual text hint for an adjacent control.

## When To Use

Use Tooltip when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Tooltip to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See tooltip.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and tooltip.html.
