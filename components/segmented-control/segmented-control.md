# Segmented Control

## Purpose

A compact grouped control for switching modes.

## When To Use

Use Segmented Control when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Segmented Control to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See segmented-control.schema.json for the source contract.

## Variants

- single-select
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
