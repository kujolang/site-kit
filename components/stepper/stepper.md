# Stepper

## Purpose

A numeric input with increment and decrement actions.

## When To Use

Use Stepper when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Stepper to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See stepper.schema.json for the source contract.

## Variants

- number
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and stepper.html.
