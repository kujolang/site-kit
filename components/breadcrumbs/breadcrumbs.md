# Breadcrumbs

## Purpose

A navigational trail that shows the current page location.

## When To Use

Use Breadcrumbs when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Breadcrumbs to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See breadcrumbs.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and breadcrumbs.html.
