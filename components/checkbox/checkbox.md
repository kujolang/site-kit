# Checkbox

## Purpose

A binary input that can be checked or unchecked.

## When To Use

Use Checkbox when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Checkbox to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See checkbox.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
