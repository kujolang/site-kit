# Pagination

## Purpose

A page navigation control for long result sets.

## When To Use

Use Pagination when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Pagination to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See pagination.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

## Examples

See examples.json and pagination.html.
