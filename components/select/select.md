# Select

## Purpose

A native select control with label and options.

## When To Use

Use Select when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Select to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See select.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and select.html.
