# Image

## Purpose

A responsive image frame with optional caption.

## When To Use

Use Image when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Image to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See image.schema.json for the source contract.

## Variants

- figure
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
