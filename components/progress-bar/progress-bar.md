# Progress Bar

## Purpose

A horizontal progress meter for determinate completion.

## When To Use

Use Progress Bar when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Progress Bar to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See progress-bar.schema.json for the source contract.

## Variants

- determinate
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and progress-bar.html.
