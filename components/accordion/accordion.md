# Accordion

## Purpose

A stacked disclosure control for expandable sections.

## When To Use

Use Accordion when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Accordion to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See accordion.schema.json for the source contract.

## Variants

- faq
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
