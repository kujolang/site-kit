# List

## Purpose

A semantic ordered or unordered list with consistent spacing.

## When To Use

Use List when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use List to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See list.schema.json for the source contract.

## Variants

- unordered
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and list.html.
