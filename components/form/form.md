# Form

## Purpose

A semantic form layout for labeled controls and actions.

## When To Use

Use Form when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Form to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See form.schema.json for the source contract.

## Variants

- stacked
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and form.html.
