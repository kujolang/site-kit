# Separator

## Purpose

A semantic visual divider between related sections.

## When To Use

Use Separator when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Separator to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See separator.schema.json for the source contract.

## Variants

- horizontal
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
