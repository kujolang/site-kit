# Avatar

## Purpose

A compact visual identity marker for a person, team, or object.

## When To Use

Use Avatar when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Avatar to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See avatar.schema.json for the source contract.

## Variants

- initials
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and avatar.html.
