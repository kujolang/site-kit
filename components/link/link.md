# Link

## Purpose

A text link with visible focus and hover states.

## When To Use

Use Link when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Link to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See link.schema.json for the source contract.

## Variants

- inline
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
