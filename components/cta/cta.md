# CTA

## Purpose

A conversion block with a clear next action.

## When To Use

Use CTA when the page needs this pattern as a reusable, token-driven component.

## When Not To Use

Do not use CTA to bypass semantic structure, heading order, or accessibility behavior.

## Props

See cta.schema.json for the source contract.

## Variants

- band
- inline
- stacked

## Accessibility Notes

- Prefer native HTML before ARIA.
- Keyboard access, visible focus, and accessible names are required.
- Color must not be the only means of communication.
