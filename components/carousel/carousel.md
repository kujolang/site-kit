# Carousel

## Purpose

A grouped media or content sequence with explicit navigation controls.

## When To Use

Use Carousel when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Carousel to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See carousel.schema.json for the source contract.

## Variants

- cards
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
