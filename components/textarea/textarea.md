# Textarea

## Purpose

A multi-line text input with label and help text.

## When To Use

Use Textarea when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Textarea to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See textarea.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
