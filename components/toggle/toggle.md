# Toggle

## Purpose

A binary switch-style control using a native checkbox.

## When To Use

Use Toggle when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Toggle to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See toggle.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and toggle.html.
