# Date Picker

## Purpose

A compact date-picker surface with a visible calendar grid.

## When To Use

Use Date Picker when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Date Picker to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See date-picker.schema.json for the source contract.

## Variants

- calendar
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

## Examples

See examples.json and date-picker.html.
