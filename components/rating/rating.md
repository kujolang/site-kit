# Rating

## Purpose

A rating display or input for qualitative feedback.

## When To Use

Use Rating when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Rating to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See rating.schema.json for the source contract.

## Variants

- five-point
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and rating.html.
