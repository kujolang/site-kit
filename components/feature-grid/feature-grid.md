# Feature Grid

## Purpose

A responsive list of capabilities or benefits.

## When To Use

Use Feature Grid when the page needs this pattern as a reusable, token-driven component.

## When Not To Use

Do not use Feature Grid to bypass semantic structure, heading order, or accessibility behavior.

## Props

See feature-grid.schema.json for the source contract.

## Variants

- two-column
- three-column
- dense

## Accessibility Notes

- Prefer native HTML before ARIA.
- Preserve semantic text structure and slotted interactive focus.
- Color must not be the only means of communication.
