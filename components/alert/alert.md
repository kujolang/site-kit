# Alert

## Purpose

A status message for success, warning, error, or neutral feedback.

## When To Use

Use Alert when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Alert to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See alert.schema.json for the source contract.

## Variants

- neutral
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
