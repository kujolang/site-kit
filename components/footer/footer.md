# Footer

## Purpose

A semantic page footer for navigation, metadata, and legal links.

## When To Use

Use Footer when the page needs this pattern as a reusable, token-driven component.

## When Not To Use

Do not use Footer to bypass semantic structure, heading order, or accessibility behavior.

## Props

See footer.schema.json for the source contract.

## Variants

- simple
- columns
- product

## Accessibility Notes

- Prefer native HTML before ARIA.
- Preserve semantic text structure and slotted interactive focus.
- Color must not be the only means of communication.

## Agent Usage Notes

- Read footer.schema.json before using or changing this component.
- Keep CSS values tokenized.
- Fix reusable component source when this pattern fails validation.

## Examples

See examples.json and footer.html.
