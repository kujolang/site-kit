# Icon

## Purpose

A small symbolic marker with an accessible name when meaningful.

## When To Use

Use Icon when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Icon to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See icon.schema.json for the source contract.

## Variants

- line
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
