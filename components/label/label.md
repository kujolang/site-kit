# Label

## Purpose

A compact text label for form fields or metadata.

## When To Use

Use Label when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Label to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See label.schema.json for the source contract.

## Variants

- field
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
