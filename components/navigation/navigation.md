# Navigation

## Purpose

A semantic navigation region for primary or secondary links.

## When To Use

Use Navigation when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Navigation to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See navigation.schema.json for the source contract.

## Variants

- primary
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and navigation.html.
