# Progress Indicator

## Purpose

A compact step or status indicator for multi-step flows.

## When To Use

Use Progress Indicator when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Progress Indicator to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See progress-indicator.schema.json for the source contract.

## Variants

- steps
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.
