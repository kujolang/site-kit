# File Upload

## Purpose

A file input drop area with a clear label.

## When To Use

Use File Upload when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use File Upload to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See file-upload.schema.json for the source contract.

## Variants

- dropzone
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and file-upload.html.
