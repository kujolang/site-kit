# Radio Button

## Purpose

A single-choice input within a related option group.

## When To Use

Use Radio Button when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Radio Button to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See radio-button.schema.json for the source contract.

## Variants

- default
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and radio-button.html.
