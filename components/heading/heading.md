# Heading

## Purpose

A typographic heading pattern with optional supporting text.

## When To Use

Use Heading when a page or application needs this interface pattern with SiteKit tokens and accessibility defaults.

## When Not To Use

Do not use Heading to bypass semantic HTML, heading order, token usage, or keyboard accessibility.

## Props

See heading.schema.json for the source contract.

## Variants

- section
- compact

## Accessibility Notes

- Prefer native HTML before ARIA.
- Interactive controls need visible focus and keyboard access.
- Color must not be the only means of communication.

See examples.json and heading.html.
