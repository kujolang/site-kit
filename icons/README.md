# Tabler icons

Curated outline subset from Tabler Icons v3.46.0, MIT licensed. Source: https://github.com/tabler/tabler-icons/tree/v3.46.0/icons/outline . Bundled symbols: sun, moon, search, menu-2, x, rotate-clockwise, code, link, external-link, arrow-up-right, check, brand-github, chevron-down, layout-dashboard, info-circle.

Use `<svg class="sk-glyph" aria-hidden="true" focusable="false"><use href="/assets/sitekit/icons/tabler.svg#sun"></use></svg>` inside a named button. Keep icons/LICENSE.txt with the sprite. External use requires same-origin HTTP; embed the symbol for file:// consumers. Add needed icons from the same pinned upstream version, preserving its license; no runtime CDN or whole-library JavaScript dependency.
