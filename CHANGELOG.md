## [1.0.0] - 2026-08-08

- Declared the stable source-vendored contract for tokens, themes, schemas, semantic templates, generated CSS, layout recipes, documented accessibility and responsive behavior, and representative static consumers.
- Kept `private: true`; SiteKit v1 ships as a GitHub source/dist release and is not published to npm.
- Added version-consistency, formatting, Markdown-link, generated-drift, browser/accessibility, package-content, license, and deterministic release-archive gates.
- Added generated `dist/sitekit.css`, optional `dist/sitekit.js`, a machine-readable manifest, Departure Mono assets and license, and the canonical SiteKit MIT license.
- Documented progressive behavior hooks for dropdown menus, popovers, drawers, dialogs, tooltips, theme controls, focus containment, Escape dismissal, and focus restoration.
- Completed the generated component index for all 85 schema-backed components and retained the stable component snapshot.
- Added clean `file://` and local HTTP consumer checks plus current Chromium, Firefox, and WebKit coverage at desktop, tablet, and mobile widths in light and dark themes.
